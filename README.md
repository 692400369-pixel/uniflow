# UniFlow 🎓

UniFlow is a student management web application designed to help university students organize their academic life in one place.

## ✨ Features

- 🔐 Student Login & Registration
- 📚 Course Management
- 📝 Assignment Tracking
- 📅 Weekly Schedule
- 🎯 Goals & Progress Tracking
- ⏱️ Focus Mode with Timer
- 🧮 GPA Calculator
- 🌙 Dark / Light Mode
- 🔎 Search Courses
- 👤 Student Profile

## 🛠️ Technologies

### Frontend
- Angular
- TypeScript
- HTML
- CSS

### Backend
- Node.js
- Express.js
- TypeScript
- MongoDB
- Mongoose
- JWT Authentication
